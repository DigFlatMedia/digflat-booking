# DEPLOY_BOOKING — DigFlat Media Booking App

Hand this file to Cowork to do the full deploy walkthrough.

---

## What we're deploying

**App:** `digflat-booking` — Express + EJS booking app for DigFlat Media  
**Repo:** DigFlatMedia/digflat-booking (private)  
**Host:** Render (Starter plan, $7/mo, Ohio region)  
**Subdomain:** book.digflatmedia.com → Render  
**DNS:** Squarespace (bryan manages CNAMEs)

---

## Step 1 — Create GitHub repo

1. Go to https://github.com/organizations/DigFlatMedia/repositories/new
2. Name: `digflat-booking` · Private · No template
3. Create repo, note the SSH URL

In the project directory (`~/Desktop/CoWork/digflat-booking` or wherever it lives):

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin git@github.com:DigFlatMedia/digflat-booking.git
git push -u origin main
```

---

## Step 2 — Create Render service

1. https://dashboard.render.com → New → Blueprint
2. Connect GitHub → select `DigFlatMedia/digflat-booking`
3. Render detects `render.yaml` and proposes the service — confirm
4. It will flag `sync: false` env vars — enter them now (Step 3)

---

## Step 3 — Set secret env vars in Render

In Render → Environment, set these (all marked `sync: false`):

| Key | Value | Where to get it |
|-----|-------|-----------------|
| `ADMIN_PASS` | Strong password | Make it up |
| `RESEND_API_KEY` | `re_...` | https://resend.com/api-keys |
| `GOOGLE_CLIENT_ID` | `...apps.googleusercontent.com` | Step 4 below |
| `GOOGLE_CLIENT_SECRET` | `GOCSPX-...` | Step 4 below |
| `WAVE_API_TOKEN` | Full-access token | Step 5 below |
| `WAVE_BUSINESS_ID` | UUID | Step 5 below |
| `WAVE_WEBHOOK_SECRET` | Signing secret | Step 6 below |
| `GOOGLE_MAPS_API_KEY` | Optional | Step 7 below |

`SESSION_SECRET` is auto-generated by Render — leave it.

---

## Step 4 — Google OAuth credentials

1. https://console.cloud.google.com → Select/create project `digflat-booking`
2. APIs & Services → Library → Enable **Google Calendar API**
3. APIs & Services → Credentials → Create Credentials → OAuth client ID
   - Type: **Web application**
   - Name: `DigFlat Booking`
   - Authorized redirect URIs: `https://book.digflatmedia.com/admin/google/callback`
4. Copy **Client ID** and **Client Secret** → paste into Render env vars

---

## Step 5 — Wave API token + business ID

1. Log into https://www.waveapps.com
2. Click your profile/avatar (top right) → **Developer Portal** → **Manage Applications**
3. Create a new app → **Full Access Token** → copy it → `WAVE_API_TOKEN`
4. Go back to Wave dashboard → the URL contains your business ID:  
   `https://www.waveapps.com/accounting/xxxx-xxxx-xxxx/...` → copy UUID → `WAVE_BUSINESS_ID`

Wave will auto-create a "DigFlat Booking Service" product on first invoice.

---

## Step 6 — Wave webhook

Set this up **after** the app is live (you need the public URL first):

1. Wave Developer Portal → Webhooks → Add webhook
2. URL: `https://book.digflatmedia.com/webhook/wave`
3. Events: `invoice.update`
4. Save → copy the **Signing Secret** → set `WAVE_WEBHOOK_SECRET` in Render

---

## Step 7 — Google Maps API key (optional)

Only needed for the >50-mile distance auto-flag. Skip if not needed.

1. Google Cloud Console → APIs & Services → Credentials → Create API Key
2. Restrict it to **Distance Matrix API**
3. Paste into `GOOGLE_MAPS_API_KEY`

---

## Step 8 — DNS (Squarespace)

1. Log into Squarespace → Domains → digflatmedia.com → DNS Settings
2. Add a CNAME record:
   - Host: `book`
   - Points to: `<your-render-service>.onrender.com` (get this from Render dashboard after deploy)
   - TTL: 3600
3. In Render → your service → Settings → Custom Domains → add `book.digflatmedia.com`
4. Render auto-provisions TLS. Takes ~5 min.

---

## Step 9 — Connect Google Calendar (one-time)

Once the app is live and DNS resolves:

1. Navigate to `https://book.digflatmedia.com/admin/google`
2. Enter your admin credentials (ADMIN_USER: `bryan`, ADMIN_PASS: what you set)
3. Click **Connect Google Calendar** → authorize with the Google account that holds your work calendar
4. You'll be redirected back — status shows **Connected**

This is a one-time step. Tokens are stored on Render's persistent disk (`/var/data/google-token.json`).
